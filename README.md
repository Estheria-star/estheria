## 这是什么

- 校园网络 ARG「星恬的宇宙」的**最后一站**：一场解谜的终点，也是礼物盒
- **门是锁着的**：没有通关时访问，只会看到一句「门还锁着」，不泄露任何内容
- 通关后（进度记录在你自己的浏览器里），终章内容才会展开

## 关于剧透

- 本仓库只包含站点本体，**不含任何谜题答案或通关线索**

- 单文件、零依赖、纯前端
